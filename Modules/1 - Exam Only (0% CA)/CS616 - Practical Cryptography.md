## 📖 Overview

Topics covered may include but are not limited to: Symmetric cryptography implementation and cryptanalysis. Hash Functions and authentication. Public key cryptography and cryptanalysis. Emerging concepts. Difference between secure systems and textbook implementations. Elliptic curve cryptography. NTRU systems. Mathematical and non-mathematical attacks.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Understand the principles of practical cryptography.
- Implement the ideas covered in the module both in code and on paper.
