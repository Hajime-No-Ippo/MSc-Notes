## 📖 Overview

This module provides an introduction to hybrid mobile development with Javascript libraries or frameworks which are used for building user interfaces for mobile applications. The course will focus on handling the view layer for platform independent web and mobile applications. Students will be introduced to the capabilities and limitations of modern mobile platforms and the challenges which are posed by this development environment. In particular, the module will deal with providing an effective user interface for mobile devices. Solutions to managing application data within the hybrid mobile application will be discussed using Object Oriented Programming (OOP) approaches. Through appropriate coursework and a team project students will gain experience in the design and development of mobile application using the React Javascript library. Students will learn how the mobile applications they frequently use work and how these applications are developed. A discussion of the enterprise scale requirements (performance, scalability, availability, and security) of mobile applications will also be discussed during the course. The course requires no previous experience of Javascript or application development. However, some programming knowledge in another high-level programming language is assumed.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Describe the capabilities and limitations of mobile platforms that affect hybrid application development and deployment.
- Describe the challenges that hybrid mobile development has in providing an effective user interface.
- Describe the technology and business trends impacting modern mobile application development.
- Design and develop introductory level hybrid mobile applications using a mobile application development framework such as React Javascript.
- Design solutions to manage application data in mobile applications using approaches such as cloud-based databases.
- Describe and explain the enterprise scale requirements (performance, scalability, modifiability, availability, and security) of mobile applications.
