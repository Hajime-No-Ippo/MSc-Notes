## 📖 Overview

User-centred software engineering teaches all relevant design and engineering principles and practices for the wholistic development of software with a strong user perspective. The module includes User Experience Design (UXD) and Software Processes (SP) within the broader framework of Software Engineering.
The module begins by introducing the concepts of human-centred design. This includes user research, wireframing and prototyping, and mobile UX. A number a cases studies are considered that exemplify the design process. This approach leads to the development of a design document. The module then introduces state-of-the-art software engineering practices (e.g., Agile, Scrum) which provide the mechanism for implementation.
On completion of the module students will be able to
1) conduct user research and evaluate design evaluations with users
2) select software processes,
3) plan and monitoring software projects
4) analysing and designing software.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Introduce theories, principles, and models for UX design and software (life-cycle) modelling based on examples and case studies
- Describe research methods used in the creation of human centred software[CM1.1]
- Create UX designs for a (mobile) application or website in the form of clickable prototypes for user testing
- Analyse and design software using current techniques, e.g. UML
- Evaluate the outcomes and the process of a software development project
