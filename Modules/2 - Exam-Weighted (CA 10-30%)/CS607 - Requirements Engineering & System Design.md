## 📖 Overview

Introduction to requirements engineering and software design. Behavioural and non-behavioural requirements. Gathering, validating and tracing requirements. Development methodologies, test driven development. Analysis and design with UML (Unified Modeling Language), UML tools. Use Case, sequence and collaboration models, Class diagram, State machines, Activity diagrams, Component and Deployment diagrams. Elaborating and decorating diagrams, tailoring UML. Verification, specification and the OCL (Object Constraint Language). Describing and applying software patterns. Case studies, sample problems and projects. Leveraging assistive technologies (LLM like ChatGPT, Copilot, Codex) for requirements & design.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Select and apply various requirements elicitation and documentation techniques.
- Create verifiable user requirements for various software projects.
- Model and communicate around software systems using UML.
- Employ GenAI for requirements understanding and realization into code.
- Collaborate effectively with clients and teammates on a software system.
- Apply and evaluate various software design patterns.
- Design for a comprehensive, high-quality software system situated in a problem context.
- Assess a software project.
