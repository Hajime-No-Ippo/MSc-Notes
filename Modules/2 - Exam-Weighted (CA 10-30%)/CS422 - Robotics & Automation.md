## 📖 Overview

This module provides an introduction to Robotics. The main focus is on building basic mathematical methods for describing and controlling the motion of robotic systems.� The components of the anatomy of a typical robot are developed (e.g. sensors, actuator, controller).� This is brought together to provide a description of the kinematic (DH matrix methods) and dynamic robot control. Standard robot configurations are presented. This is followed by an introduction to the topic of articulated motion planning. The module finishes with an introduction to Robot Navigation and Locomotion.� �The Robotics Operating System (ROS)�is introduced and covered throughout the course to provide practical experience of robot software development and control.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Discuss real robots and robots in popular culture and society. Discuss the ethical issues this presents.
- Describe the anatomy and features of a typical robot and evaluate mobility of a simple machine using number synthesis, joints and pairs.
- Describe the motion of articulated robots.
- Identify suitable actuators and controllers for a specific task.
- Understand control strategies.
- Describe the approaches and techniques to describe mobile robot motion, localisation, mapping and path planning.
- Have an appreciation of the software used to control and model robotic systems.
