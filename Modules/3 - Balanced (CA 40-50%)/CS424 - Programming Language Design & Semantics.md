## 📖 Overview

This module is about the design of programming languages. In particular, it focuses on evolution of programming languages, different types of programming paradigms, parsing techniques, semantic analysis, type checking. This module also introduces graph based specification languages, write a specification for a design/program/model/requirement and encode a program (loop-free) into scheme-like language (SAT/SMT encodings).

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Know the history of programming languages.
- Understand programming language design principles.
- Understand different types of programming paradigms.
- Understand how parsing, semantics analysis and, type checking are done in a compiler.
- Be able to write basic formal specifications of a program.
- Be able to encode a program into a scheme-like language.
