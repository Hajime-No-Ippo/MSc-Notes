## 📖 Overview

A combination of advanced object-oriented programming techniques and concepts in object-oriented languages are discussed. Topics covered include Classes, Objects, Encapsulation, Information Hiding, Inheritance, Composition, Object Lifetimes, Operator Overriding, Operator Overloading, Polymorphism, Dynamic Binding, Templates, Exception handling.

Students will learn techniques to ensure long-term code quality and good design, through topics such as code smells, software metrics, refactoring, design patterns and understanding trade-offs/technical debt.

This module embraces the approach of AI pair programming. Students will be encouraged to use such tools (e.g. CoPilot), where appropriate in order to gain the experience they will likely need in an industrial setting.

## 🎯 Learning Outcomes

On successful completion of the module, students should be able to:

- Construct object oriented programming solutions for reuse, using abstract data types that incorporate encapsulation, data abstraction, information hiding, and the separation of behavior and implementation.
- Construct multiple-file or multiple-module programming solutions that use classes, subclasses, class hierarchies, inheritance, parameterised classes, generics and polymorphism to reuse existing design and code.
- Employ AI pair programming effectively while avoiding common pitfalls.
- Identify code smells and use code metrics to evaluate code quality.
- Employ refactoring techniques and design patterns to improve code quality.
